# Shreshta Nagesh | Portfolio

Animated, neon data-themed portfolio. Plain HTML, CSS and JavaScript, with no build step.

## Structure
- `index.html`: page content
- `css/styles.css`: styles and theme colors (see `:root` variables)
- `js/main.js`: animations, tabs, theme toggle
- `assets/images/`: project screenshots (add your own)
- `assets/docs/`: resume PDF (optional)

## Publish with GitHub Pages
Settings > Pages > Deploy from a branch > `main` / `(root)`.

## Edit
- Colors: change the variables at the top of `css/styles.css`.
- Projects: edit the `W` array in `js/main.js`.
- Skills: edit the `S` array in `js/main.js`.
